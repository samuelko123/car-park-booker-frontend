# Car Park Booker - Frontend

<p>There was a third-party car park booking system. It has no wait-list feature.</p>
<p>Some users tried to book but failed. Some users cancelled in the last minute.</p>
<p>This app will retry booking for users, so that cancelled spot can be utilised.</p>

<p>Used together with https://github.com/samuelko123/car-park-booker-backend.</p>
